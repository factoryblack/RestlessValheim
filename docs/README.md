# Documentation map

Start with [player guides](player/README.md) for current behaviour and controls. Maintainers should use [building and releases](maintainers/building.md), [public documentation](maintainers/public-docs.md), and [reliability checks](maintainers/reliability.md).

[Expansion settings](expansion-settings.md) describes the current shared settings API and UI checks. `catalogue.yaml` remains the sole feature/status catalogue; `versions.yaml` owns package pins and `cook.yaml` owns recipe definitions.

Other files at this level include design, artwork, integration and audit records. They preserve useful rationale and visual checklists. Explicit historical banners identify older branch-specific records; their baselines and completed tasks are not a current release plan. Follow source code and current maintainer/player guidance when an older record differs.
