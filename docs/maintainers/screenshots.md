# Screenshot capture brief

All package pages now have visible **(screenshot coming)** placeholders. Capture full original PNGs; no cropping or graphic design is needed before upload.

Use the same UI scale throughout. Prefer 2560×1440 or larger; 1920×1080 is usable. Use daylight or well-lit interiors, with no debug overlay, console, chat popup or cursor obscuring the subject. Keep the UI visible in interface captures and hide it only for furniture/world shots if convenient. Supply installed versions and other visible mods once with the batch.
