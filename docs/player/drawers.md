# RestlessDrawers guide

Build modular storage furniture with the capacity and progression of familiar chests.

> (screenshot coming) — A mixed-tier drawer wall with populated item fronts.

## Choose a cabinet

| Drawer | Matching chest | What stays the same |
| --- | --- | --- |
| Wood | Wood chest | Slots, recipe and unlock |
| Personal | Personal chest | Slots, recipe, unlock and personal access |
| Reinforced | Reinforced chest | Slots, recipe and unlock |
| Black metal | Black metal chest | Slots, recipe and unlock |

If you can build the matching chest, you can build its drawer. Drawers do not grant extra capacity or early access to a storage tier.

## Build a wall

Select the cabinet from the hammer and use its snap points to join neighbouring cabinets. Tiers share the same footprint, so wood and black metal can occupy the same arrangement. Current main fits cabinets just under a metre high and uses corner snap points; turn the piece as needed and line up the intended corners.

Each cabinet is **one container**. Its drawer fronts are not separate inventories. Open the cabinet to use the normal container controls.

The fronts show the four most abundant item stacks so you can recognise supplies from across the room. Vanilla chests remain usable, and personal drawers retain the matching chest's privacy.

## Integrations

Core sees drawers as containers for supported crafting, building, quick-stack and ground-item routing. [Storage](storage.md) can browse eligible nearby drawers. [Piles](piles.md) remains the separate single-resource bulk-storage option.

Drawers do not provide structural support for a building. Their furniture support treatment prevents the normal support graph from collapsing the cabinet; this is not a substitute for beams and foundations.

## Settings and updates

The F8 Drawers page identifies the loaded module and links its package page. There are no drawer-specific gameplay sliders.

Recent main changes adjust cabinet dimensions and snapping. Compare the changelog and the installed release before expecting identical placement behaviour in an older build. The versioned history below the current package notes remains the reference for older releases.
