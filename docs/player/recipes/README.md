## Reading the guide

**New dish** means a custom addition; **Changed vanilla recipe** keeps the original item but changes its ingredients; **Vanilla reference** connects the food graph without adding a second item. An empty ingredient list on a reference is not a free crafting recipe.

Each entry gives its output quantity and station level when specified by the graph. Sideboards are not edible. Food regeneration is per tick, not per second.
