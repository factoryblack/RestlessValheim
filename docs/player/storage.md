# RestlessStorage guide

**Everything nearby, in one place.**

The Storekeeper's Table lets you find supplies without opening each chest.

> (screenshot coming) — Storage browser with one resource selected, combined total and source rows.

## Build and browse

1. Build the **Storekeeper's Table** from the hammer's Furniture category at a workbench. Its recipe uses wood, fine wood and bronze nails.
2. Put it near accessible containers and supported resource piles.
3. Use the table to open the browser.

Search names, filter item types and sort the list. Select an entry to inspect its total and the locations holding it. Item variants stay separate instead of combining incompatible stacks.

## Take what you need

Choose a quantity and take the selected material into your inventory. Withdrawal uses the real source containers; it does not create a second copy for you.

If the requested amount will not fit, the remainder stays in or is returned to its source. A failed container transaction also returns its reserved items. For Make-order output in Workshop, use the board's order collection instead: the Storekeeper's Table is a nearby-storage browser.

Nearby piles can be listed and withdrawn from. Access restrictions still apply, including personal containers.

## Range and discovery

The table uses Core's nearby-storage range and access rules. It does not search unloaded storage elsewhere in the world.

Opening the browser can mark listed materials as handled for normal recipe discovery. Station requirements still apply, and trophies are not marked as collected through this action.

The table is an interaction point, not another chest with its own stored inventory.

## Settings and limitations

Use **F8 → RestlessStorage** for the local window toggle. Core owns the shared range settings.

The current browser is designed around mouse and keyboard; complete controller grid navigation is still a follow-up. Local withdrawal has been playtested, while multiplayer ownership and interrupted transfers need broader in-game coverage.
