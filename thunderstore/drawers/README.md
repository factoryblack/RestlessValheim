# RestlessDrawers

**Same storage progression. A tidier storeroom.**

Build modular cabinets that fit together and show what they hold from across the room.

> (screenshot coming) — Mixed drawer tiers arranged into a populated storage wall.

## Familiar capacity

| Cabinet | Matches |
| --- | --- |
| Wood drawer | Wood chest |
| Personal drawer | Personal chest |
| Reinforced drawer | Reinforced chest |
| Black metal drawer | Black metal chest |

Each cabinet keeps the matching chest's slot count, recipe and unlock. Personal drawers keep personal access. This is storage furniture, not an extra-capacity upgrade.

## Build an arrangement

Tiers share a footprint so you can combine them in a wall or stack. Use the cabinet's snap points to align neighbouring pieces and turn them to face your room.

Each cabinet is **one container**. The fronts show its four most abundant stacks; the visual drawers are not separate inventories. Open the cabinet to use the familiar container controls.

## Fits the collection

Core treats eligible drawers as containers for crafting, building, quick-stack and ground-item routing. Storage can browse their contents. Piles remains the separate option for single-resource bulk storage.

Vanilla chests remain valid. Drawer support behaviour is intended for the furniture, not as structural support for buildings.

## Start here

1. Install Drawers with Core.
2. Unlock the corresponding vanilla chest.
3. Build its cabinet using the hammer and fill it through the container window.

The current source includes a smaller cabinet and corner-snapping update. Older releases may have different placement dimensions; consult the guide and changelog when updating existing arrangements.

Drawers is included in the current Restless Valheim pack. Its F8 page identifies the module; it has no separate gameplay sliders.

## Installation and help

Requires **RestlessCore**, BepInExPack and Jötunn. A mod manager installs the required dependencies. Use matching released plugin versions on all clients and the server.
