# RestlessDrawers

A furniture chest for every vanilla chest. Same storage, better walls.

If you can build the biome’s chest, you can build its drawer. Same slots. Same materials. Same unlock. The cabinet is one container — click anywhere sensible and you get the normal chest window. The fronts only show what is inside.

Each cabinet, legs included, is 95cm with snap points on the corners of a 94cm cell. Neighbours overlap by 1cm. A corner can catch a floor or another cabinet. Rotation stays yours, and the alt-place key turns snapping off. One cabinet fits between floors a metre apart.

Needs **RestlessCore**, plus BepInEx and Jötunn. Everyone on the server should be on the same minor version.

**Restless Piles** stay the specialised bulk stacks. Vanilla chests stay valid. Drawers are not Chest+. They tile against a wall and tell you wood / resin / feathers from across the room.

## The four

- **Wood drawer** — wood chest
- **Personal drawer** — personal chest (still only you)
- **Reinforced drawer** — reinforced chest
- **Black metal drawer** — black metal chest

If a 1.0 chest prefab is missing, that drawer is skipped and the rest still load.

Install the **Restless Valheim** modpack later, or Core then this. This package does not replace RestlessCore.
