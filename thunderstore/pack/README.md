# Restless Valheim

**Less friction. Clearer information. Still Valheim.**

Restless Valheim installs the collection and its dependencies in one mod-manager profile. Build a more organised base, cook meaningful meals and feasts, and spend less time shuffling materials.

The pack is an installation bundle. Its features come from the individual plugins, which can also be installed separately.

## One consistent interface

Inventory, tooltips, crafting, HUD, maps and settings share the Restless visual language. F8 gathers Core and expansion settings in one place.

## Start playing

1. Create a Valheim profile in r2modman or the Thunderstore App.
2. Install **Restless Valheim** and let the manager resolve its dependencies.
3. Launch modded and open **F8**, or Restless from the pause menu.

Plus **BepInExPack 5.4.2351** and **Jötunn 2.30.2**.

Install the same released plugins on every client and the server. Gameplay settings are host/server-controlled with locking enabled; personal controls and visual preferences remain local.

Choose individual modules if you want a smaller setup. Avoid overlapping inventory, HUD or storage-automation mods without checking the compatibility guidance.

The older **RestlessValheim** and **RestlessQOL** listings are deprecated. **Restless_Valheim** is the current collection.

The package changelog explains what each bundle update brings, with component versions underneath.
