# RestlessStorage

**Everything nearby, in one place.**

Open the Storekeeper's Table to find supplies without opening every chest in the room.

> (screenshot coming) — Storage browser with combined totals and the selected item's sources.

## Find it, then take it

Search item names, filter types and sort accessible nearby storage. Select an entry to see the combined quantity and where it is stored, then choose how much to take.

Item variants stay separate. Withdrawal moves the real items from their source; overflow goes back, and failed container transactions return their reserved items.

## Your storeroom, connected

Nearby drawers, chests and supported resource piles can appear on the same sheet. Range and access follow Core's storage rules, including private-container restrictions.

The table does not scan unloaded storage across the world and does not hold a separate chest inventory of its own.

## Build the table

1. Install Storage with Core.
2. Build the **Storekeeper's Table** from the hammer's Furniture category at a workbench, using wood, fine wood and bronze nails.
3. Place it near your stores, open it and select a resource.

> (screenshot coming) — Storekeeper's Table in an organised storeroom.

Opening the browser can help discover recipes for materials listed there, while required stations and levels still apply. Trophies are not marked collected through this action.

Use **F8 → RestlessStorage** for the local window toggle. Core controls search range. The current browser is designed for mouse and keyboard; complete controller grid navigation is still a follow-up.

Storage is included in the current Restless Valheim pack. See the guide for collection rules and multiplayer limitations.

## Installation and help

Requires **RestlessCore**, BepInExPack and Jötunn. A mod manager installs the required dependencies. Use matching released plugin versions on all clients and the server.
