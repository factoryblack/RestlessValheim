# RestlessStorage

The Storekeeper's Table. One place to see what the chests around you are holding, and to take what you need.

Use the table to browse accessible nearby containers, search and sort their contents, inspect combined totals and see where each entry is stored. Item variants are kept separate. The window uses the shared Restless UI kit and has a local toggle under F8 → RestlessStorage.

This is a **read-only browser preview**. Quantity controls preview the amount and added weight; the Take button is disabled. Actual withdrawal needs the owner-authoritative transfer service. No items are removed or created by this window.

The preview uses Core's nearby-storage range and access rules. It does not scan unloaded or global storage. Requires the updated Core DLL containing StorageWindowApi as well as RestlessStorage.dll.

Built at the workbench from wood, fine wood, and bronze nails. Furniture, under the hammer. It is not a chest.

Needs **RestlessCore**, plus BepInEx and Jötunn. Everyone on the server should be on the same minor version.

Not in the Restless Valheim pack yet.
